# Web and desktop appearance

Open **Settings** → **Appearance** to choose the theme, interface transparency, fonts, and code
display preferences used by the web and desktop apps.

## Diff appearance

**Diff colors** switches between the standard red/green palette and an orange/blue palette. The
selected colors apply to added and deleted rows, line-number gutters, and diff headers.

**Diff markers** switches between compact bar indicators and classic `+` and `−` markers at the
start of changed lines.

These preferences are stored on the current device and apply to the main diff panel, pull request
reviews, and inline review-comment diffs.
